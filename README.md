# COS 106 Term Project: Web Development & Interactive Task Manager

**Author:** Moses Ndubuisi Moore  
**Institution:** MIVA Open University  
**Course:** COS 106 – Web Technologies  
**Focus Areas:** Web Engineering, Defensive UI Design, Cybersecurity  

---

## 📌 Project Overview
This repository contains a multi-page web application engineered to demonstrate foundational web technologies including **HTML5**, **CSS3**, and **JavaScript DOM manipulation**. 

The application serves as a personal academic portfolio showcasing responsive layout design, client-side input validation, and an interactive task planner with custom checkbox controls.

---

## 📂 Project Structure
- `index.html` — Homepage introducing the project and navigation.
- `about.html` — Developer profile highlighting career aspirations in DevSecOps & Cybersecurity.
- `projects.html` — Interactive portfolio grid featuring badges and hover animations.
- `planner.html` — Dynamic task manager supporting task creation, checkbox completion, and deletion.
- `contact.html` — Form with real-time client-side validation.
- `css/styles.css` — Centralized design stylesheet implementing Flexbox and CSS Grid.
- `js/planner.js` — Event-driven JavaScript logic for task rendering.

---

## 🚀 Key Features
- **Responsive Architecture:** Fully functional across desktop, tablet, and mobile displays.
- **Interactive Planner:** Add, toggle, and delete tasks dynamically without page reloads.
- **Defensive UI & Security Practices:** Client-side sanitization to mitigate script injection threats.
