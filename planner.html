Academic Task Management System

Organize assignments, readings, and project deadlines efficiently.

How to use this planner:
  • Add Task: Type a task into the box below and click Add Task (or press Enter).
  • Mark Complete: Click directly on any task's text to mark it as completed (strikethrough).
  • Delete Task: Click the red Delete button next to any task to remove it.
